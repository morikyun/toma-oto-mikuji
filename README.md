# とおまの音みくじ

5つの質問から、總水とおま・カミムスヒの8作品51曲に出会う非公式ファンサイトです。

公開サイト：[とおまの音みくじ](https://toma-oto-mikuji.pages.dev/)

このリポジトリではサイトのソースと修正依頼を管理します。修正内容をPRで確認し、もりきゅんさんがマージすると既存のCloudflare Pagesへ反映する構成です。

## 修正・相談を登録する

[修正・相談を登録する](https://github.com/morikyun/toma-oto-mikuji/issues/new/choose) から、近い内容を選んでください。登録にはGitHubアカウントが必要です。

| 相談したいこと | 選ぶフォーム |
| --- | --- |
| 曲名・紹介文・リンクなどを直したい | 文章・曲名・リンクを直したい |
| 新しい案内ページを作りたい | 新しいページを作ってほしい |
| 表示が崩れる・ボタンが動かない | 表示がおかしい・うまく動かない |
| 文字や色、操作をわかりやすくしたい | 見やすく・使いやすくしてほしい |
| 音みくじに機能を追加したい | 機能を追加・改善してほしい |
| どこに書くか迷っている・質問したい | 質問・相談したい |

該当するページのURLと「今はどうなっているか」「どうなってほしいか」を書いてください。例：「結果画面の説明文がスマートフォンでは読みにくいので、文字を少し大きくしたい」。技術的な説明は不要です。

Issueと添付画像は公開されます。個人の連絡先、非公開資料、歌詞全文、パスワードやトークンは書かないでください。個人情報に関する相談は、サイトの [お問い合わせ窓口](https://toma-oto-mikuji.pages.dev/privacy/#contact) をご利用ください。リンク変更は運営者が公式情報などで確認します。

## 修正から公開まで

1. 運営者がIssueを確認し、CodexにIssue URLを渡してPR作成を依頼します。
2. PRで自動チェックを行い、morikyunが差分を確認してプレビュー公開を承認します。
3. 確認用サイトで内容を確認し、morikyunが **Squash and merge** を押すと本番へ自動公開します。

Issue登録だけでAIが自動着手する設定ではありません。PRの作成だけで本番は変わりません。プレビュー承認と本番へのマージは、もりきゅんさんが行います。

初回のSecret登録と詳しい操作は [Issueから確認・公開まで](docs/GITHUB_WORKFLOW.md) を参照してください。

## 手元で確認する

Node.js 24とPython 3を利用します。外部パッケージのインストールは不要です。

```sh
npm run check
npm test
npm run prepare:cloudflare
npm run dev
```

`http://127.0.0.1:4173/` を開きます。

`dist/` が編集元、`cloudflare-pages/` は `npm run prepare:cloudflare` で作る公開用フォルダーです。

楽曲データの基礎は `research/catalog.json`、解説は `dist/notes/` にあります。`npm run notes` は別途ローカルの発信アーカイブを用意した場合の書き出し用です。GitHub Actionsはこのコマンドを実行せず、コミットされた公開用データを使います。

`qa/`、生成済みの公開フォルダー・ZIP、認証情報、非公開の研究資料はGit管理対象外です。アプリを修正する方は [AGENTS.md](AGENTS.md) も確認してください。

音源・歌詞全文・非公開の資料・認証情報は含みません。曲の紹介は制作側の解釈であり、ご本人の公式な推薦ではありません。
